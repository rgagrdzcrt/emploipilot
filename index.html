Synchronisation téléphone / PC

Les statuts, notes, candidatures, critères, modèles et infos sont enregistrés dans un gist GitHub secret de ton compte, puis récupérés sur chaque appareil. Un gist secret n’est pas listé publiquement mais reste lisible par quiconque obtient son lien.

Crée un jeton classique sur GitHub : Settings → Developer settings → Tokens (classic) ↗, avec uniquement la case gist cochée. Colle-le ici sur chacun de tes appareils. Il reste enregistré dans ce navigateur uniquement.

ZCRT est un prototype personnel. Vérifie les informations et les dates de chaque annonce avant de postuler. Les envois de candidature restent manuels.
