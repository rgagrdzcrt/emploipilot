Statuts, notes, candidatures, critères, modèles et infos sont enregistrés dans un gist GitHub secret de ton compte, puis récupérés sur chaque appareil. Un gist secret n’est pas listé publiquement mais reste lisible par quiconque obtient son lien.

  1. Crée un jeton classique sur GitHub : Settings → Developer settings → Tokens (classic) ↗
  2. Coche uniquement la case gist.
  3. Colle-le ici sur chacun de tes appareils. Il reste enregistré dans ce navigateur uniquement.
